Helena is a super-lightweight, cross-platform API client — a native alternative to Postman and Bruno, built with Go + Fyne. Diffable Open Collection YAML, nine auth schemes, scripting, real-time SSE & WebSocket, and a headless runner.

Why Helena

Built around three trade-offs

Postman and Bruno ship a browser engine and store collections in formats that don't diff cleanly. Helena goes the other way.

⚡ Native, no Electron

Fyne renders through OpenGL. The binary is ~35 MB and starts instantly — no bundled Chromium.

🗂️ Diffable YAML

Workspaces, collections, and requests are plain Open Collection YAML you can review and merge like any source. Secrets stay out of it.

🧪 Boring, debuggable Go

No JS sandbox to babysit, no exotic concurrency. The runtime is go test-able end to end.

What's inside

A lot of client, very little weight

🔐 Nine auth schemes

Basic, Bearer, API Key, OAuth 2.0 (incl. auth-code + PKCE), OAuth 1.0a, WSSE, AWS SigV4, Digest, NTLM.

📡 Real-time

Stream Server-Sent Events and open bidirectional WebSocket sessions — both hand-rolled on the standard library.

🔣 Variables everywhere

A layered {% raw %}{{var}}{% endraw %} scope chain across URL, query, headers, and body, with a live resolved-URL preview.

📜 Scripting & tests

Pre/post JavaScript hooks with a curated helena.* API, plus test()/expect() and no-code assertions.

🔗 Chaining & runner

Run other requests first and feed results forward; run a whole collection headlessly with helena run.

🔄 Import & export

Import OpenAPI / Swagger / WSDL / Postman; export to cURL, wget, fetch, Python, or Go.
